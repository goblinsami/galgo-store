# MVP

El MVP entrega una web publica de afiliacion para galgos con:

- Home con propuesta, destacados, guias, categorias y aviso afiliado.
- Listado de productos con filtro por categoria.
- Ficha de producto con boton afiliado instrumentado.
- Listado y detalle de guias publicadas desde Supabase.
- Endpoint interno para registrar clics afiliados.
- Migracion SQL, RLS y seed reproducible.
- Tests unitarios de validacion y utilidades criticas.

Queda fuera: administracion, usuarios, IA, scraping, precios, carrito, pagos y redes sociales.
